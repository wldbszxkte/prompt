Godot 게임 만들기 프롬프트

아래 프롬프트를 복사해서 AI 채팅에 붙여넣으세요. AI가 Godot 4.7로 게임 만드는 과정을 한 단계씩 알려줍니다.

사용 팁

  • 막히면 캡처해서 보내기Godot 화면이나 빨간 에러 메시지를 캡처해서 AI에게 보내면 훨씬 빨리 해결돼요.
  • "정리해줘"로 저장하기대화가 길어지면 AI가 앞 내용을 잊어요. "정리해줘"라고 하고 나온 내용을 메모장에 저장해 두세요.
  • 내 그림·사진 넣기직접 그린 그림이나 찍은 사진을 AI에게 보내면, 게임에 넣는 방법을 알려줘요.
  • 새 채팅에서 이어 만들기새 채팅에 이 프롬프트를 붙여넣고, 바로 아래에 저장해 둔 정리를 붙여넣으면 이어서 만들 수 있어요.

무료 그림·소리 받기 - Kenney

Kenney의 그림과 소리는 모두 CC0이라 출처를 적지 않아도 자유롭게 쓸 수 있어요.

  1. 아래 목록에서 내 게임에 맞는 팩을 눌러 들어가요.
  2. Download를 누르고, 기부 화면이 나오면 Continue without donating을 눌러요.
  3. 받은 zip 파일의 압축을 풀어요.
  4. PNG 폴더 안의 그림을 Godot의 assets/images 폴더로 끌어다 놓아요.
  5. 팩 이름과 파일 이름을 AI에게 알려주면, 어떤 파일을 쓰면 되는지 골라줘요.

실사 느낌 사이트 다운로드 방법 (Poly Haven, ambientCG)

학교 컴퓨터에서는 1K로 받으세요. 4K, 8K는 파일이 너무 커서 Godot이 느려져요.

Poly Haven - 3D 모델 (상자, 가구, 바위 등)

  1. 위 메뉴에서 Models → 원하는 모델을 클릭해요. (오른쪽 위 국기를 누르면 한국어로 바꿀 수 있어요)
  2. 오른쪽 위 보라색 줄에서 4K를 눌러 1K로 바꿔요.
  3. 그 옆 형식 버튼을 눌러 glTF를 골라요. (처음엔 Blender로 되어 있어서 꼭 바꿔야 해요)
  4. Download를 눌러 zip 파일을 받고 압축을 풀어요.
  5. 압축 푼 폴더째 Godot의 assets/models로 끌어다 놓고, .gltf 파일을 씬에 끌어다 놓아요.

Poly Haven - 하늘 배경 (HDRI)

  1. HDRIs → 마음에 드는 하늘 클릭 → 1K 또는 2K, 형식 HDR → Download
  2. Godot에서 WorldEnvironment → Environment → Background Mode를 Sky로 바꿔요.
  3. Sky → 새 Sky → Sky Material에 새 PanoramaSkyMaterial → Panorama 칸에 .hdr 파일을 끌어다 놓아요.

ambientCG - 바닥, 벽 재질 (Poly Haven의 Textures도 같은 방법)

  1. 위 검색창에 영어로 검색해요: grass, rock, wood, brick, metal 등
  2. 마음에 드는 재질을 클릭하고 1K-JPG를 눌러 zip 파일을 받아요.
  3. 압축을 풀면 그림이 여러 장 나와요. _Color(색깔), _NormalGL(울퉁불퉁한 느낌, NormalDX 말고 GL!), _Roughness(반짝이는 정도) 3장을 써요.
  4. 바닥이나 벽 MeshInstance3D → Material Override → 새 StandardMaterial3D
  5. Albedo → Texture에 _Color, Normal Map의 Enabled 체크 후 Texture에 _NormalGL, Roughness → Texture에 _Roughness를 넣어요.
  6. 넓은 바닥에서 그림이 쭉 늘어나 보이면 UV1 → Triplanar를 체크해요.

다 외울 필요는 없어요. AI에게 "Poly Haven에서 받은 ○○ 넣고 싶어"라고 하면 단계별로 알려줘요.
